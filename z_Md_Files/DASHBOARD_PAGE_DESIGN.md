## 🧠 DASHBOARD STRUCTURE (LOCKED)

### 1️⃣ Identity Core
**Purpose:** Immediate clarity and authority.
- **Content:** Name, Role, Engineering Philosophy.
- **Visuals:** Floating name, slow motion, no aggressive animation.

### 2️⃣ System Universe (Interactive 3D Core)
**Purpose:** Visually explain how you build systems.
- **Structure:**
    - **Central Core:** Intelligence (AI/ML).
    - **Orbitals:** IoT, Backend, Applications.
    - **Flows:** Animated data streams (Sensors -> API -> AI).
- **Interaction:** Hover dims others, Click navigates.
- **Tech:** CSS 3D Transforms / Three.jsLite.

### 3️⃣ Project Categories
**Purpose:** Primary Navigation.
- **Categories:** IoT, AI/ML, Web, Desktop, API/Backend.
- **Style:** Semi-3D cards.

### 4️⃣ Capability Signals (Replaces Skill Bars)
**Purpose:** Show engineering strengths, not tools.
- **Format:** "System Architecture → High"
- **Style:** Clean 2D, text-based.

### 5️⃣ Live System / Active Work
**Purpose:** Show you are building *now*.
- **Content:** "🟢 Currently Building: [Project Name]"
- **Style:** Micro-3D accent.

### 6️⃣ Impact Metrics
**Purpose:** Credibility without noise.
- **Content:** Systems built, integration levels.

### 7️⃣ Current Focus
**Purpose:** Show direction.
- **Content:** GenAI, LLM Orchestration, Automation.

### 8️⃣ Contact Action
**Purpose:** Strong Exit.
- **Actions:** GitHub, LinkedIn, Email, Resume.
